# 沈广隆内容审计与品牌页面结构计划

> **For implementation:** 先完成事实确认和素材归档，再批量填充 Shopify 页面与 Hydrogen 模板。

**目标：** 建立可核验、可扩展的品牌内容体系，优先完成“品牌故事”和“工艺与传承”，同时为后续商品页、购买指南和 Journal 提供统一内容来源。

**原则：** 参考网站只借鉴信息架构，不直接复制文字；历史年份、人物称号、奖项、收藏和国礼信息必须分别标记来源和确认状态。

## 3. “品牌故事”正式页面结构

页面目标：让用户在 3 分钟内理解品牌来历、传承关系和今天的业务边界。

### 模块 A：首屏定位

- 标题：沈广隆：从龙泉炉火开始的制剑传承
- 副标题：Since 1885 · Longquan, China
- 一句话说明：家族制剑、龙泉工艺、当代收藏与练习场景。
- CTA：了解工艺 / 查看商品 / 联系订制
- 素材：品牌 Logo、工作室或锻造现场横图。

### 模块 B：品牌摘要

只写经过确认的事实，回答：

1. 何时开始；
2. 在哪里传承；
3. 主要制作什么；
4. 今天服务哪些用户。

### 模块 C：历史时间轴

建议先使用 6—8 个确认节点，而不是把所有年份一次性堆上页面，并确保六代传承在时间轴或人物模块中有清晰落点：

- 起源；
- 剑铺形成；
- 代表性工艺或赛事节点；
- 传承人接续；
- 第六代的学习、参与或当代职责；
- 非遗、老字号或大师称号；
- 当代工作室。

每个节点必须包含：年份、事件、人物、来源状态、图片或证据。未核验节点先不展示。

### 模块 D：传承人物

采用统一卡片模板：

- 姓名和代际；
- 学艺起点；
- 主要工艺职责；
- 可核验称号；
- 代表作品；
- 个人详情页或 Journal 文章链接。

### 模块 E：品牌原则

建议围绕三句话展开：

- 对材料诚实；
- 对工艺耐心；
- 对每一件作品负责。

这部分属于品牌表达，不写成无法验证的历史事实。

### 模块 F：今天的沈广隆

明确区分四种业务：

- 现有目录商品；
- 练习和使用场景；
- 收藏与展示作品；
- 大师订制和咨询。

### 模块 G：信任与咨询

- 证书、报道和展览入口；
- 购买前须知入口；
- 联系咨询 CTA；
- 配送和法规提示。

## 4. “工艺与传承”正式页面结构

页面目标：让用户看懂一件作品如何完成，而不是只看到“手工制作”四个字。

### 模块 A：工艺总览

用一张工艺流程图展示：选材 → 锻造 → 整形 → 热处理 → 打磨 → 刻饰 → 装配 → 检查 → 交付。

### 模块 B：材料与器型

- 剑身或刀身材料；
- 装具材料；
- 木质剑鞘或其他配件；
- 不同材料对重量、手感、外观和保存的影响。

所有材料名称以实际产品资料为准，不用“顶级”“绝对锋利”等无法统一衡量的词。

### 模块 C：核心工序

每道工序采用同一结构：

1. 工序名称；
2. 这一步解决什么问题；
3. 匠人如何判断质量；
4. 对最终手感或外观的影响；
5. 过程照片或短视频；
6. 关联商品。

首批建议先做 6 个工序：锻造、整形、淬火、打磨、刻饰、装配。后续再扩展。

### 模块 D：手工差异说明

明确告诉用户：

- 纹理、色泽和细节可能存在差异；
- 图片不能完全代表实物；
- 手工差异不是无条件的质量保证；
- 具体规格以商品页和确认报价为准。

### 模块 E：传承不是口号

用人物、工作台、工具、师徒协作和日常生产照片说明技艺如何传下去。避免只放荣誉文字。

### 模块 F：历史作品与当代商品边界

单独加入说明：历史订制、收藏、礼仪或展览作品仅用于展示品牌和工艺，不代表当前可售库存。

### 模块 G：延伸阅读与咨询

- 品牌故事；
- 大师介绍；
- 购买指南；
- 大师订制；
- 联系咨询。

| 商品图 | 每个商品至少 5 张 | 商品详情幻灯片 |
| 评论素材 | 真实评论或暂不展示 | 商品详情页 |

## 6. 实施顺序

1. 店主确认事实核验台账中的历史、人物、称号和作品边界；
2. 收集品牌故事和工艺照片；
3. 先完成品牌故事页面；
4. 再完成工艺与传承页面；
5. 建立大师人物模块和认证/媒体模块；
6. 将内容拆分回首页、商品页和购买指南；
7. 最后批量整理商品详情、评论和 Journal；
8. 每个页面完成中文版本后，再制作英文版本，避免两种语言内容不一致。

## 7. 第一轮验收标准

- 重要页面不再只有一段简介；
- 每个页面至少有一个明确目标和 CTA；
- 每个历史事实都有来源状态；
- 历史作品和可售商品明确分开；
- 工艺页至少有 6 个可阅读模块；
- 品牌故事页至少有时间轴、人物、品牌原则和当代业务四个主体模块；
- 图片都有用途说明和 alt 文本；
- 商品详情页后续可以接入幻灯片、评论和推荐商品，而不需要重新设计页面结构。
