# 前台凑数文案审计与处理记录

## 目标

前台只保留能帮助客户理解品牌、工艺、作品或购买流程的内容。开发状态、素材占位、重复免责声明和没有新信息的口号，不再作为页面主体出现。

## 审计分类

| 类别 | 当前表现 | 处理方式 |
| --- | --- | --- |
| 开发状态泄漏 | 「资料会逐步整理」「本地原型」「之后可以替换」 | 直接删除；若页面需要影像，直接说明影像记录的内容 |
| 泛化的资料状态 | 「先做可阅读的索引」「待核验内容」 | 用已核对的年份、人物、资质、节目名称和来源链接替代 |
| 重复边界说明 | 「不代表每一件现售商品」「不代替商品规格」在多个页面反复出现 | 保留一次短说明；商品规格、库存、配送与法规说明仍留在购买相关页面 |
| 空泛工艺口号 | 「工艺不是一句手工制作」「工艺需要被看见」 | 改为材料、工序、人物或影像的具体说明 |
| 有客户价值的风险提示 | 尺寸、重量、库存、交期、目的地、承运商、开刃与保存提示 | 保留，改为直接、短句式说明 |

## 本轮处理清单

### 直接移除

- 首页：`先用真实影像建立工坊的节奏；之后可以替换……`
- 首页：`这里先用真实工作室影像建立品牌氛围；之后可以替换……`
- 工艺页：`影片先放在本地原型中，之后可替换……`
- 资质页：`资料会逐步整理`、`先从品牌故事开始`、`待核验内容，不先写成销售承诺`
- 资质页：`本地原型先呈现资料层级……`
- 图片说明：`本地高保真原型`、`先核对来源，再放大叙事`

### 改为来源明确的内容

- 品牌传承起点：1885 年。
- 当前品牌资质页列示的认定：2010 年「中华老字号」以及「沈广隆宝剑锻制技艺保护基地」。
- 当前品牌资质页列示的传承人：第四代沈新培、第五代沈州及其公开资质。
- 当前品牌资质页列示的节目与专题：CCTV-1《我有传家宝》、CCTV-7《手艺人》、CCTV-9《传承》、凤凰卫视龙泉铸剑文化专题、山东卫视《中国面孔》、安徽卫视《百家姓》。
- 页面增加公开来源链接，让客户可以回看原始资料；不把未经核对的证书编号、奖项编号或商品级别承诺写入页面。

## 来源与边界

本轮事实内容以沈广隆现行「品牌资质与媒体报道」页面、品牌传承文章和公开人物资料页交叉参考。历史文章中个别年份的表述存在差异时，页面优先采用现行资质页能直接核对的表述，并在页面底部提供来源链接。

「资质与媒体报道」只说明品牌公开背景，不自动表示每一件在售商品具有相同资质。商品页仍以具体图片、规格、库存、交期与购买前说明为准。

## 验收标准

- 资质页不再出现「本地原型」「之后可替换」「资料会逐步整理」「待核验内容」等开发状态文案。
- 资质页首屏能直接看到 1885、2010、保护基地、沈新培、沈州等具体信息。
- 媒体部分直接显示节目名称与播出平台，不使用泛化的「节目记录」凑数句。
- 首页、工艺页、保养页不再暴露素材临时替换计划。
- 购买与法規边界仍然可见，但不重复占据品牌内容主体。
